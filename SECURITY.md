# Security Policy

We take security seriously. If you discover a vulnerability in VERTEX, please follow responsible disclosure guidelines.

Reporting a vulnerability

1. Prefer GitHub's private security advisories: https://docs.github.com/en/code-security/security-advisories
2. If you cannot use the private advisories, open a new issue in the repository and label it `security` and mark it as confidential.
3. Provide a clear description of the issue, reproducible steps, and an impact assessment.

What to expect

- We'll acknowledge receipt within a few business days.
- We'll work with you to triage, fix, and release patches.
- We may ask for additional information or provide a timeline for fixes.

If you need to contact maintainers directly and prefer not to use GitHub, please indicate your preferred contact method in the initial confidential issue and we will respond.
