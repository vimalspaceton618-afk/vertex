# Contributing to VERTEX

Thank you for your interest in contributing! We welcome bug reports, feature requests, documentation fixes, and code contributions.

How to contribute

1. Fork the repository.
2. Create a branch for your change named `feature/<short-description>` or `fix/<short-description>`.
3. Make your changes and add tests where relevant.
4. Commit with a meaningful message and push to your fork.
5. Open a Pull Request against the `main` branch in the upstream repository.

Pull request guidelines

- Describe the problem you are solving and the approach you used.
- Reference relevant issues (e.g., Fixes #123).
- Keep PRs small and focused when possible.
- Add tests for logic changes and run the test suite locally.

Code style

- Follow existing project code style. If ESLint / Prettier configs exist, run them before committing.

Reporting security issues

If your change affects security-sensitive code or you discover a vulnerability, please follow the steps in SECURITY.md and **do not** disclose the details publicly until the issue is resolved.

Thank you — maintainers will review PRs as time permits.
